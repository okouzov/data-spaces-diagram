# Interactive Data Spaces Diagram

This isolated project contains a rewritten 16:9 version of the data spaces diagram.

- `interactive_data_spaces_diagram.jsx` is the React component version.
- `diagram-data.js` holds the bilingual English/Bulgarian content shared by the component and the preview.
- `index.html` is a dependency-free local preview with the same layout behavior and language toggle.

The journey view uses one shared-height grid row, so the animated diagram and the description panel stay aligned.
